## 放在哪、怎么推

仓库推在 **B2 机器**（`pyaissh @b2`）上，因为那台有 `gh` 且已登录。
本地工作目录只留这份说明，源码不在本地。

以后要更新备份：

```bash
# 1. 本地重新组装（改了什么就重同步什么）
B=/tmp/xhh-mcp-backup
cp -r /root/.local/share/uv/tools/xiaoheihe-cli/lib/python*/site-packages/xhh_operator/. $B/xhh_operator/
rm -rf $B/xhh_operator/__pycache__ $B/xhh_operator/*.pyc $B/xhh_operator/*.bak-*
cp /root/工作目录/AIlife/docs/小黑盒*.md $B/docs/
cp /root/工作目录/AIlife/tools/xhh-{card,sticker,reply-batch}.py $B/tools/

# 2. 打包传上去
cd /tmp && tar czf xhh-mcp-backup.tgz xhh-mcp-backup
python3 /root/.dsh/skills/pyaissh/pyaissh.py upload @b2 --local /tmp/xhh-mcp-backup.tgz --remote /tmp/xhh-mcp-backup.tgz

# 3. B2 上覆盖、提交、推
python3 /root/.dsh/skills/pyaissh/pyaissh.py exec @b2 --cmd '
  cd /tmp && tar xzf xhh-mcp-backup.tgz && cd xhh-mcp-backup &&
  git add -A && git commit -m "更新：<改了什么>" && git push'
```
