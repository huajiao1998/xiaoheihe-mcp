# 小黑盒表情代码白名单

格式是 `[cube_xxx]`，直接写在评论或帖子正文里。**写错一个字就会原样显示成文本**——比如 `[cube_狗头]` 不存在，正确的英文名是 `[cube_doge]`。

下面这份是从 10 篇热帖、220 个真实表情实例里统计出来的（排除了我自己发的）。

## 高频（闭眼用）

| 代码 | 大概什么意思 |
|---|---|
| `[cube_鳄鱼]` | 乐子人 / 看戏 |
| `[cube_喜欢]` | 喜欢 |
| `[cube_摘墨镜]` | 装酷 / 无奈 |

## 规矩

- 表里没有的别用，宁可不用表情。
- 英文名和中文名混着来（`[cube_doge]` 是英文，`[cube_鳄鱼]` 是中文），别自己猜。
- 一条评论最多一个，别堆。
